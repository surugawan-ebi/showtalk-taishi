# ShowTalk Taishi brand assets

The production raster assets in this directory use the project's **AI kamon**
identity: an ukiyo-e inspired Prince Shōtoku listens to several original AI
crests, representing multiple persistent Koe coordinated through one Slack
front end.

| File | Intended use |
| --- | --- |
| `showtalk-taishi-concept-v3.png` | README, articles, and brand overview with the `ai` in `Taishi` highlighted in vermilion |
| `showtalk-taishi-icon-v2.png` | Square Slack, GitHub, npm, and app icon optimized for small-size legibility |

These images were generated with OpenAI ImageGen on 2026-08-25 from a
project-specific creative brief. The AI kamon are original abstract marks;
they are not third-party AI product logos. The current production set uses
solid backgrounds. A transparent or vector master has not yet been produced.

Slack's standard app manifest does not carry the app icon. To use the candidate
icon as Taishi's default Slack App identity, upload
`showtalk-taishi-icon-v2.png` under **Basic Information → Display Information**
in the Slack App settings. Per-Koe message identities remain configured
separately through `icon_url` or `icon_emoji`.
